MST Annotation Helper

v1.3.0
Active on MST
Extension Master Toggle Enable or disable all annotation shortcuts

Shortcut Toggles

⏸️
Spacebar Toggle pause/play main audio playback
🔢
Number Keys 1 to 9 Select audio annotation card #1 to #9
⏱️
Square Brackets [ / ] Set Start Time [[] and End Time []]
💾
Shift + Enter Save / Update selected annotation
⏩
Arrow Keys ← / → Seek audio backward / forward (5s)
⚡
Arrow Keys ↑ / ↓ Speed up / slow down audio by 0.5x

Preferences

Floating Page Button Show "Manage Timings" button on web page
On-Screen HUD Toasts Display visual action badges in top-right
